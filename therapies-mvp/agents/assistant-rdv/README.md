# Assistant Prise de Rendez-vous

**Rôle** : aide à structurer le processus d'accueil et de relance des clients (confirmation, rappel, relance).

**Exemple d'usage** : "Rédige-moi un SMS de rappel de rendez-vous pour demain à envoyer à mes clients."

**Fichiers**
- `system-prompt.md` — prompt système de l'agent
- `config.ts` — métadonnées (id, nom, description)
