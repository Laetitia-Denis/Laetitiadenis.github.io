# Coach du Praticien

**Rôle** : accompagne le praticien lui-même sur sa posture professionnelle, son organisation et sa motivation.

**Exemple d'usage** : "Je me sens débordé entre mes séances et l'administratif, comment je m'organise mieux ?"

**Fichiers**
- `system-prompt.md` — prompt système de l'agent
- `config.ts` — métadonnées (id, nom, description)
