# Copywriter Bien-être

**Rôle** : rédige des contenus marketing (posts, descriptions, bios) conformes au vocabulaire non-médical.

**Exemple d'usage** : "Écris-moi un post Instagram pour annoncer mes nouvelles séances de Reiki à distance."

**Fichiers**
- `system-prompt.md` — prompt système de l'agent
- `config.ts` — métadonnées (id, nom, description)
