# Coach Positionnement

**Rôle** : aide à définir la cible, la différenciation et le message de marque du praticien.

**Exemple d'usage** : "Je n'arrive pas à me différencier des autres naturopathes de ma ville, aide-moi à trouver mon positionnement."

**Fichiers**
- `system-prompt.md` — prompt système de l'agent
- `config.ts` — métadonnées (id, nom, description)
